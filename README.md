# Bleach Co.

E-commerce de camisetas artesanais alvejadas à mão. Cada peça é produzida sob encomenda e possui padrão estético único.

## Rodar localmente

### 1. Backend (porta 3003)
```bash
cd backend
npm install
node server.js
```

### 2. Frontend (porta 3004)
```bash
npm install
npm start
# Acesse: http://localhost:3004
```

### 3. Build de Produção
```bash
npm run build
```
