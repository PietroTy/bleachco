ℹ Para desenvolvedores — integração Mercado Pago

Para ativar o pagamento real, substitua o placeholder no js/main.js:

  1. Crie uma conta no Mercado Pago Developers
  2. Gere um Access Token de produção
  3. No backend (Node/PHP/Python), faça POST para /checkout/preferences com os itens do carrinho
  4. Retorne o id da preferência e monte a URL: https://www.mercadopago.com.br/checkout/v1/redirect?pref_id=SEU_PREF_ID
  5. Configure o webhook de notificação para atualizar o status do pedido automaticamente
  6. A URL de retorno após pagamento deve apontar para confirmacao.html
